# SpeakUp English Phuket — Static Site

Plain HTML/CSS site, ready for GitHub Pages or any static host.

## Files
- `index.html` — main page
- `styles.css` — all styling
- `assets/hero-classroom.jpg` — hero image

## Deploy to GitHub Pages
1. Create a new GitHub repository (e.g. `speakup-english-phuket`).
2. Upload these files to the repo root (or push via git).
3. In the repo: **Settings → Pages → Source: Deploy from a branch → main / root → Save**.
4. Your site will be live at `https://<username>.github.io/<repo>/` in ~1 minute.

## Local preview
Open `index.html` in a browser, or run:
```
python3 -m http.server 8000
```
